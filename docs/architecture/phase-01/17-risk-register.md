# 17 — Technical & Operational Risk Register

**Project:** Projukti Labs (`projuktilabs.tech`)  
**Review Date:** 2026-11-06  

---

| Risk ID | Category | Risk Description | Likelihood | Impact | Severity | Mitigation & Prevention Strategy | Contingency / Fallback Plan |
|---|---|---|---|---|---|---|---|
| **RISK-01** | Runtime / Build | `vinext@1.4.3` exhibits incompatibility with a specific Next.js `16.4.5` or `@tailwindcss/turbopack` build primitive on Cloudflare Workers. | Medium | High | **High** | Execute Phase 02 POC Gate (`npx vinext check` + 17-point runtime test) before building UI pages; replace `@tailwindcss/turbopack` with `@tailwindcss/vite` or PostCSS for Vite compatibility; avoid experimental `"use cache"`. | Switch build adapter to `@opennextjs/cloudflare@1.20.16` (OpenNext for Cloudflare Workers) with zero changes to App Router pages, Drizzle schema, or domain modules. |
| **RISK-02** | Database (D1) | Bulk insert or complex multi-row Drizzle mutation exceeds Cloudflare D1's hard limit of **100 bound parameters per SQL statement**. | High (if unmanaged) | Medium | **Medium** | Implement `chunkedBatchInsert(db, table, rows)` utility in `lib/db/` that calculates `maxRows = Math.floor(90 / columnCount)` and executes chunks inside `db.batch([...])`. | Unit-test all seed scripts and multi-feature service saves with 50+ items against local and remote D1. |
| **RISK-03** | Database (D1) | Foreign key constraint errors during schema migrations (`ALTER TABLE` / table recreation in SQLite). | Medium | High | **Medium** | Prepend `PRAGMA defer_foreign_keys = ON;` to complex Drizzle SQL migrations and rehearse every migration on `projukti_labs_db_preview` before production. | Instant database rollback via `wrangler d1 time-travel restore` to pre-migration bookmark timestamp. |
| **RISK-04** | Database (D1) | Single-threaded D1 writer bottlenecks under sudden traffic spikes or unindexed queries. | Low-Medium | High | **Medium** | Serve all public pages and catalog reads through Cloudflare Cache API + KV (`s-maxage=300`); enforce composite indexes on all filter/sort columns; ban binary blobs in D1. | Enable D1 Read Replication (Global Read Replicas via D1 Sessions API) if international read traffic scales significantly. |
| **RISK-05** | Storage (R2) | Admin uploads large image/PDF through Worker request body, hitting Worker memory/body size limits, or leaves unverified orphan objects in R2. | Medium | Medium | **Medium** | Use `aws4fetch` to sign direct browser-to-R2 `PUT` URLs (`15m` expiry); verify upload via `env.R2_BUCKET.head(key)` in `/api/v1/admin/media/complete`; sweep unconfirmed uploads nightly. | For tiny icons (< 1 MB), allow optional authenticated Worker proxy upload fallback if CORS isn't configured yet in local dev. |
| **RISK-06** | Content / Brand | AI-assisted blog drafts publish inaccurate technical claims or generic low-quality prose that damages Projukti Labs' studio credibility. | Medium | High | **High** | Enforce hard schema & service rule: AI drafts save strictly as `status = 'draft'` with `is_ai_assisted = 1`; `BlogPublishWorkflow` refuses to publish unless `approved_by_user_id` is set by an authenticated human Admin. | One-click `Unpublish` in `/admin/blog` that purges KV/Edge cache immediately. |
| **RISK-07** | Infrastructure Cost / Plan | Cloudflare Queues and Cloudflare Workflows require the **Workers Paid Plan (\$5/mo)** and fail to deploy on a Free-tier account. | Medium | Medium | **Medium** | Verify Cloudflare account plan tier at the start of Phase 02 before provisioning Queues/Workflows. | If staging starts on a Free tier, `lib/cloudflare/jobs.ts` provides a clean adapter fallback that executes jobs via `ctx.waitUntil()` + Cron Triggers polling D1 `automation_jobs`. |
| **RISK-08** | Typography / UX | Mixed English (`Geist`) and Bangla (`Hind Siliguri`) text clips Bangla vowel marks (`ী`, `ু`, `ূ`, `ঁ`) due to tight English heading line-heights (`1.08`). | High (if unmanaged) | Medium | **Medium** | Apply locale/script-aware CSS rules (`:lang(bn)` or `.font-bengali`) with `line-height: 1.45` on headings and `1.78` on body text; verify across `320px–1440px` viewports in Playwright. | Dedicated visual regression snapshot tests for bilingual blog and service content. |
